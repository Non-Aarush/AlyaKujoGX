# Alya Kujo — Opera GX Mod

A custom Opera GX mod dedicated to **Alisa Mikhailovna Kujou** from *Alya Sometimes Hides Her Feelings in Russian* (*Tokidoki Bosotto Russia-go de Dereru Tonari no Alya-san*).

Designed with a sleek, atmospheric winter night aesthetic inspired by Alya's signature silver hair and ice-blue eyes.

  - Custom styled aesthetics for popular sites including Discord, Reddit, Twitch, X (Twitter), YouTube, Spotify, and GitHub.

## 🚀 Installation

### Option 1: Load Unpacked (Local / Developer Mode)
1. Open Opera GX and go to opera://extensions
2. Toggle **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select this mod folder (where manifest.json is located).
4. Head to opera://mods to enable the mod and customize which elements (wallpapers, sounds, music, web modding) you want active.

### Option 2: Pack as .crx
1. Go to opera://extensions
2. Turn on **Developer mode** and click **Pack extension**.
3. Select this folder to generate a .crx file.
4. Drag and drop the .crx file into any Opera GX window to install.

### Option 3: Install from the Opera GX Store
Install directly with a single click from the official Opera GX Store:
- **GX Store Link**: [Alya Kujo Mod on Opera GX Store](https://store.gx.me/mods/aoyk8a/alya-kujo/)

---

## ⚙️ Configuration & Customization

Once installed, manage your mod options directly in Opera GX:
- Go to opera://mods
- Click on **Alya Kujo** to select your favorite wallpaper from the collection, adjust volume levels for background music and UI sounds, or toggle web styling on/off.
